General

Si hay un juego abierto, Dársena siempre se queda en la bandeja para seguir contando el tiempo de juego. Para salir del todo: clic derecho en su icono → Salir.

Se suben al cerrar cada juego y se comprueban antes de jugar. Antes de sustituir tus partidas, Dársena guarda una copia en la carpeta .darsena-copias del juego.

Descargas

Límite de subida

Cuanta más gente comparte, más rápido baja cada port para los demás. Se guarda una copia del archivo descargado (en la carpeta .compartido del juego) para poder compartirlo; se borra al desinstalar. Tus datos de juego nunca se comparten.

Fuentes

Las fuentes son listas JSON de terceros con enlaces de descarga (torrent o directos) para juegos del catálogo. Dársena no incluye ninguna: tú decides cuáles añadir y respondes del contenido que descargas. Sin fuentes, siempre tienes la descarga oficial desde GitHub.

Avanzado

Sin token, GitHub permite 60 consultas por hora a la versión más reciente de cada port. Basta un token sin permisos.
