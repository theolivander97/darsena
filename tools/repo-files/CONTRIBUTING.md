# Cómo participar

Gracias por querer ayudar a Dársena.

- **¿Conoces un port que debería estar en el catálogo?** Pídelo con la plantilla
  [Pedir un juego](https://github.com/theolivander97/darsena-launcher/issues/new?template=pedir-un-juego.yml).
  El catálogo lo mantiene el autor y revisa cada propuesta: solo entran ports que piden tu propia copia del juego.
- **¿Algo no funciona en el launcher?** Abre un [reporte de problema](https://github.com/theolivander97/darsena-launcher/issues/new?template=reportar-un-problema.yml).
  Si el fallo es dentro de un juego, repórtalo en el repositorio de su port.
- **¿Quieres opinar sobre un juego?** Escribe tu reseña desde el propio launcher (inicia sesión con GitHub):
  se publica en [Discussions](https://github.com/theolivander97/darsena-launcher/discussions).

No se aceptan pull requests que modifiquen el catálogo.
